# NinjaOni

Minecraftサーバー用の忍者鬼ごっこゲームプラグインです。プレイヤーは忍者となり、特殊なアイテムを使用して鬼から逃走したり、鬼として忍者を捕まえたりします。

## 概要

NinjaOniは、従来の鬼ごっこゲームに忍者の要素を加えたMinecraftプラグインです。プレイヤーは忍者チームまたは鬼チームに分かれ、それぞれ専用の忍者アイテムを使用して戦略的なゲームを楽しめます。

## 主な機能

### ゲームシステム
- **チーム分け**: 鬼チーム、忍者チーム、観戦者チーム、捕獲された忍者チーム
- **ゲーム状態管理**: カウントダウン、ゲーム中、待機状態の管理
- **スコアボード**: チーム別の表示とネームタグの非表示機能
- **ワールドボーダー**: ゲームエリアの制限

### 忍者アイテムシステム
忍者と鬼がそれぞれ専用のアイテムを使用できます：

#### 忍者アイテム（逃走者用）
- **粘着玉（Nenchaku）**: 雪玉を投げて鬼を5秒間停止させる
- **ムササビ（Musasabi）**: 落下速度を低下させる
- **隠れ（Kakure）**: 透明化効果
- **煙（Kemuri）**: 煙幕効果
- **影追い（Kageoi）**: 移動に関する特殊効果

#### 鬼アイテム（追跡者用）
- **クナイ（Kunai）**: 矢を発射する
- **縮地（Shukuchi）**: 5秒のチャージ後、3秒間移動速度上昇
- **跳躍（Choyaku）**: 向いている方向に跳躍

### ゲーム機能
- **自動テレポート**: ゲーム開始時にチーム別のスポーン地点にテレポート
- **インベントリ管理**: アイテムの自動配置とクリア
- **経済システム**: ゲーム内通貨による報酬システム
- **装備システム**: 鬼チーム専用の防具セット

## 技術仕様

### 対応環境
- **Minecraft**: 1.17.1+
- **Java**: 16以上
- **Gradle**: 8.0

### 依存プラグイン
- **ProtocolLib**: プロトコル操作
- **CommandAPI**: コマンド管理

## 設定

### config.yml
```yaml
countdown-time: 3          # カウントダウン時間（秒）
game-time: 200             # ゲーム時間（秒）
warp-block-type-oni: DIAMOND_BLOCK    # 鬼用ワープブロック
warp-block-type-spec: IRON_BLOCK      # 観戦者用ワープブロック
tp-location:
  oni:                     # 鬼チームスポーン地点
    x: 75.0
    y: 4.0
    z: -60.0
  player:                  # 忍者チームスポーン地点
    x: 75.0
    y: 4.0
    z: -60.0
money-amount: 20           # 基本報酬金額
```
